## Fixed

- **Started from the menu, CodeDeck no longer adds your home folder as a project.** Without a folder it opens no project: the start page shows, or a CodeDeck already running comes to the front. `codedeck <directory>` opens a project as before; for the folder you are in, use `codedeck .`.
- **The start page shows on your main screen** the first time, at its left edge. It could come up on another monitor.
- **Project icons load**: choosing an icon for a project stayed at "Loading icons…".
