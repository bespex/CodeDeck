## What's new

- **Changes in Dirq**: with Dirq, the diff viewer of be spex, installed (0.4.0 or newer), the Changes tab lists the files and Dirq shows their diffs. A double click on a file opens it there alone, with a way to step to the other files; the "Dirq" button opens the whole change. Without Dirq, Changes shows the diffs itself as before.
- **Comments from Dirq**: in the uncommitted changes, a running turn and the changes since a snapshot you comment on lines in Dirq (a "+" in the margin, also on removed lines); each comment arrives as a line comment for your next prompt, aimed at the session of that turn. Changing or removing it in Dirq does the same here.
- **More context in Dirq**: CodeDeck lets Dirq read the repository, so it can show more lines around a change.
- **Umbrella projects**: a project that is a group's own folder (e.g. `~/projects/bespex` next to `~/projects/bespex/Qiew`) joins that group as its first row; a session of another listed project carries that project's colour at its badge.
- **Computer check**: Marq and Dirq count as "helpful" now; the descriptions say what each viewer is and what it does in CodeDeck.
- Fixed: the details of the AI usage are no longer cut off at the edge of the session column.
