## Changed

- **Fewer snapshots.** A repository inside another of your projects is saved only by the innermost one: a project above it (a group folder, your home folder) no longer adds a second or third snapshot of the same turn. A shell command saves the repository the session works in, not every repository in the project.
- **Next prompt offers your `@ai` hints.** Hints in the project's files that are not attached yet are listed below the attachments, each with its paperclip, and "attach all". They still go out only when you attach them.
- **Changes: View** is among the tools of a file row now, next to Edit.
