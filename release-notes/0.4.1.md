## Fixed

- **"Waiting in other projects" no longer fills up**: one session could show up again and again in the project list until it overflowed. Each session now shows once, with the project it belongs to.
- A session started in a folder above a project (e.g. in `~/projects/bespex`) no longer waits for you in every project below it. A session in a subfolder still shows in the project above.
- Seeing a finished turn in one project counts in every project that follows the session; the tray and desktop notices count each session once.
- The waiting part of the project list scrolls when it holds many sessions.
