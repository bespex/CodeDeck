## New

- **A menu for the project's top folder** in the file list, beside the search (⋯), and on the empty space of the tree: a new file or folder at the top, expand or collapse all folders, show the top folder in the file manager or open a terminal there.
- **Move files and folders by dragging them** in the file list: onto a folder, onto a file for its folder, or onto the empty space for the top. Several chosen entries (Ctrl/Shift) move together; nothing moves if one of them cannot.
