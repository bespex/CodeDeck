## Changed

- **Tidying up the scratch folder is shorter to read.** Files are grouped by why they are proposed: each reason shows once, folds open and ticks or unticks all its files. A single file's reason is in the tooltip over its name.
- **More files are offered for tidying up**, each group with its reason: empty files can go; to look at first are drafts of an AI session that has ended, drafts unchanged for more than 7 days, and files never looked at for more than 7 days (they used to stay for good).
- **Prompts for later land where you find them.** A new start rule asks every session to save a prompt it writes for a later session, in its project or another one, in that project's `.scratch/prompts/`. It shows there under Prepared in the session column.

## Fixed

- **The Next prompt area in the session column no longer cuts its text short** in a short window or with prepared prompts below it.
- **A prepared prompt in a new folder shows at once.** When `.scratch/prompts/` did not exist yet, a prompt laid there from outside (a session, another program) only showed after the project was opened again.
