## What's new

- **Prepared prompts**: write a prompt over time, without the risk of sending it too early. Below what is attached to your next prompt, a new "Prepared" list shows your named prompts (the three last changed, "… all n" for the rest); "+" starts a new one. A click opens a prompt in an editor right there, and the area grows for it, so it can stay open beside the deck and the file list while you look things up and copy them in. Enter is a new line and nothing is sent; it saves a moment after you stop typing. Rename it in place, copy the text to paste it into a session, or move it to the trash. Wrapped list items hang under their text. Each prompt is a Markdown file in `.scratch/prompts/` of the project, so it also opens in your own editor.
- Typing in a prepared prompt does not make the rest of the window run again: saving it no longer refreshes the git status, the `@ai` hint scan and the diffs.
